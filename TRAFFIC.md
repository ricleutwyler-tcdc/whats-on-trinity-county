# What's On, Trinity County — traffic

From Sep 12, 2026 the site counts its own page views: one beacon per view to the Women
Entrepreneurs Response Receiver (`?hit=1&s=events`), a row on the Traffic tab of the Nominations
sheet, and a daily "TRAFFIC — What's On" line in Ric's morning "WE worklist" mail. No names, no
IPs; a random per-browser id for unique visitors; Ric's own browser excluded via `?me=ric`.
The beacon lives in `generator/template.html`, so the weekly rebuild keeps it.
